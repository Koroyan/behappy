# Legacy scripts (pre-2.0)

These scripts target the BeHappy 1.x app: screens, prompts and a client-side
OpenAI key that no longer exist. They are kept for reference only and are not
part of the 2.0 build or test suite.

Current checks live in `scripts/qa/` and run through `npm run qa:*`.

Do not run `reset-project.js`: it is the Expo template script and moves `app/`
out of the way.
