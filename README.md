# BeHappy - მენტალური ჯანმრთელობის აპლიკაცია

React Native/Expo აპლიკაცია AI-ზე დაფუძნებული ფსიქოლოგიური მხარდაჭერისთვის.

## ✨ ფუნქციონალი

- 📝 **Умный дневник**: ведение дневника с поддержкой ИИ и анализом настроения
- 🤖 **AI ფსიქოლოგი**: პერსონალიზებული სესიები OpenAI GPT-4-თან
- 🎨 **არტ თერაპია**: ნახატების ანალიზი AI-ის მიერ
- 🫁 **Дыхательные практики**: управляемые техники дыхания для релаксации
- 📚 **Курсы здоровья**: структурированные программы для развития навыков
- 🧠 **ფსიქოლოგიური ტესტები**: განწყობისა და მენტალური მდგომარეობის შეფასება
- 🃏 **ინტერაქტიული ბარათები**: ემოციური რეფლექსიისთვის
- 📈 **პროგრესის თვალყურება**: დეტალური სტატისტიკა და ანალიტიკა

## 🚀 დაწყება

### წინაპირობები

- Node.js (v16 ან უფრო ახალი)
- npm ან yarn
- Expo CLI: `npm install -g @expo/cli`
- OpenAI API key

### ინსტალაცია

1. **რეპოზიტორიის კლონირება**
```bash
git clone <repository-url>
cd beHappy
```

2. **დამოკიდებულებების ინსტალაცია**
```bash
npm install
```

3. **გარემოს ცვლადების კონფიგურაცია**
```bash
# კოპირება .env.example-დან .env-ში
cp .env.example .env

# .env ფაილში OpenAI API key-ის მითითება
EXPO_PUBLIC_API_KEY=your_openai_api_key_here
```

4. **პროექტის გაშვება**
```bash
# Development mode
npm start

# iOS simulator-ზე
npm run ios

# Android emulator-ზე
npm run android

# Web browser-ში
npm run web
```

## 🔧 კონფიგურაცია

### OpenAI API Setup

1. მიდით [OpenAI Platform](https://platform.openai.com/api-keys)
2. შექმენით ახალი API key
3. დაამატეთ `.env` ფაილში:
```
EXPO_PUBLIC_API_KEY=sk-proj-your-key-here
```

⚠️ **უსაფრთხოება**: არასოდეს არ აიტვირთოთ .env ფაილი Git-ში!
